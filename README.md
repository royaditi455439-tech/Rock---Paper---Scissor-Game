# Rock Paper Scissors Game 🎮

A simple **Rock-Paper-Scissors game built with Python**.
The player enters a choice, and the computer randomly selects Rock, Paper, or Scissor. The program then compares both choices and displays the result.

## 📌 Project Overview

This project was created as a beginner-level Python project to practice:

- Python input and output
- Conditional statements (`if`, `elif`, `else`)
- Random selection
- String methods
- Basic game logic

## ⚙️ How It Works

1. The user chooses **Rock, Paper, or Scissor**.
2. The computer randomly selects one option.
3. The program compares the two choices.
4. The result is displayed as:
   - You Win
   - Computer Wins
   - It's a Tie

## 🧠 Game Rules

| User Choice | Computer Choice | Result |
|---|---|---|
| Rock | Scissor | User Wins |
| Paper | Rock | User Wins |
| Scissor | Paper | User Wins |
| Same Choice | Same Choice | Tie |
| Other combinations | — | Computer Wins |

## 💻 Technologies Used

- Python 3
- Google Colab
- Python `random` module

## ▶️ How to Run

1. Open the Python notebook in Google Colab.
2. Run the code.
3. Enter one of the following choices:

```text
Rock
Paper
Scissor
```

4. The computer will make a random choice.
5. The program will display the winner.
